# K2BS — 小児矯正患者管理

医院のスタッフが患者情報をまとめて確認するための初期版です。Python 3.12、Flask、SQLite を使用します。外部APIや有料サービスは不要です。

## できること

- カルテ番号・氏名・生年月日・メモの登録、番号と氏名による検索
- 患者ごとの来院記録、治療内容、入金日・金額・支払方法等の記録
- 患者ごとの入金累計（請求残高や未収金の計算ではありません）
- 撮影日・メモ付きの写真保存と表示
- 共有パスワードでのログイン、ログアウト（8時間で期限切れ）

## 最初に動かす

このクラウド環境では、端末で次のコマンドを実行します。既存のチェックアウトを使い、新しい Git worktree は作りません。

```sh
cd /workspace/K2BS-AI-
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py set-password
.venv/bin/python app.py
```

`set-password` で12文字以上の共有パスワードを2回入力します。入力内容は表示されません。パスワードをチャットやソースに書かないでください。同じコマンドで変更できます。

サーバーはポート5000で起動し、同じマシンからのみ接続を受け付けます。このオンボーディング画面にはアプリを表示するプレビュー機能がないため、環境の公開だけではブラウザーで使えるようになりません。医院のPCで試す場合はこのリポジトリを取得し、そのPCで同じ手順を実行して、ブラウザーでローカルのポート5000を開いてください。複数端末からの利用は次の公開・運用構成の整備が必要です。

まずは架空の患者を登録し、「来院」「治療」「入金」をそれぞれ追加し、架空の画像を保存して確認してください。

## 保存場所とバックアップ

既定では `data/clinic.sqlite3` に患者と記録、`data/photos/` に写真、`data/password.hash` にパスワードのハッシュ、`data/session.key` にセッション署名鍵を保存します。`data/` と `.venv/` は Git 管理対象外です。`K2BS_DATA_DIR` で保存場所を変更できます。

手動バックアップはアプリを停止してから `data/` 全体を安全な場所へコピーします。復元も停止中に全体を戻してください。バックアップにも患者情報が含まれます。自動バックアップや暗号化は未実装です。

写真は JPEG・PNG・WebP、リクエスト全体12MB以下、画像2500万画素以下に対応します。最大2400pxのJPEGとして再保存し、EXIF等のメタデータを除去します。診断用原本の保管を代替する機能ではありません。

## 検証

```sh
cd /workspace/K2BS-AI-
.venv/bin/python -m unittest discover -s tests -v
```

一時フォルダーを使用し、認証・CSRF・患者登録・重複防止・検索・記録の永続化・金額の検証・画像アップロードと未認証での画像アクセス拒否を検証します。実データは変更しません。

## 実際の患者情報を扱う前に

これは架空データで機能を確認するための試作です。共有パスワード方式で、個人ごとのアカウント・権限・操作履歴、ログイン試行の制限、登録情報の編集・削除、返金や未収金の管理は未実装です。TLS、永続ストレージ、暗号化、バックアップと復元検証、医院の情報管理方針に沿った運用設計も必要です。

現在の開発サーバーをそのままインターネットに公開しないでください。共有利用に進むときは、個人ログインとアクセス制限を実装し、本番用サーバー・HTTPS・監査とバックアップを整備してください。HTTPS環境では `K2BS_HTTPS=1` によりSecure Cookieを有効にします。
